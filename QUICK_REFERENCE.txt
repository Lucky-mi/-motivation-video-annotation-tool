📌 唯一推荐脚本
────────────────────────────────────────────────────────────────
  python scripts/run_search.py

  ⚠️ 不要使用其他脚本！

═══════════════════════════════════════════════════════════════

📋 配置文件
────────────────────────────────────────────────────────────────
  位置: config/search_config.py

  关键设置:
  ✓ KEYWORD_SET = "minimal"        # 关键词集合
  ✓ VIDEOS_PER_KEYWORD = 5         # 每个关键词搜索数量
  ✓ AI_REVIEW_WORKERS = 5          # 并发审核数

═══════════════════════════════════════════════════════════════

🔑 关键词集合
────────────────────────────────────────────────────────────────
  minimal (6个)    → 快速测试    → 3-5分钟
  standard (12个)  → 日常使用    → 5-10分钟
  extensive (24个) → 更全面      → 15-25分钟
  mega (100+个)    → 大规模采集  → 1-2小时

═══════════════════════════════════════════════════════════════

⚡ 核心优化
────────────────────────────────────────────────────────────────
  ✅ 延迟优化      → 速度提升10倍
  ✅ 跳过已存在    → 避免重复下载
  ✅ 并发AI审核    → 5个线程并发
  ✅ 智能评分      → 节省API成本
  ✅ 格式兼容性    → 修复下载失败

═══════════════════════════════════════════════════════════════

📊 运行流程
────────────────────────────────────────────────────────────────
  1. 批量搜索视频
  2. 智能评分预筛选 (跳过低分视频)
  3. 批量下载 + 并发AI审核
  4. 自动删除未通过视频
  5. 生成统计报告

═══════════════════════════════════════════════════════════════

📁 输出文件
────────────────────────────────────────────────────────────────
  data/search_results.json     搜索结果（包含评分）
  data/youtube_links.json      视频数据库（包含审核）
  data/Youtube_videos/         下载的视频文件
  data/video_scores.json       评分学习数据

═══════════════════════════════════════════════════════════════

🔧 常用命令
────────────────────────────────────────────────────────────────
  # 查看配置
  python config/search_config.py

  # 运行采集
  python scripts/run_search.py

  # 保存日志
  python scripts/run_search.py 2>&1 | tee collection.log

═══════════════════════════════════════════════════════════════

🎯 最佳实践
────────────────────────────────────────────────────────────────
  1. 首次运行: 使用 "minimal" 测试
  2. 日常采集: 使用 "standard"
  3. 并发数: 从5开始，稳定后可增加到7
  4. 定期检查: video_scores.json 了解学习情况

═══════════════════════════════════════════════════════════════

❓ 故障排查
────────────────────────────────────────────────────────────────
  问题: 使用了旧的理论性关键词
  解决: 检查 KEYWORD_SET = "minimal" (不是默认值)

  问题: 速度很慢
  解决: 增加 AI_REVIEW_WORKERS = 7

  问题: 下载失败
  解决: pip install --upgrade yt-dlp
