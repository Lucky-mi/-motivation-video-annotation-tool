# 视频标注可视化检查平台使用说明

## 功能概述

这是一个专门用于检查和审核 `data/annotations_test` 目录中标注文件的可视化平台，主要功能包括：

1. **视频播放对照**: 加载视频文件，对照标注内容进行播放
2. **标注段列表**: 显示所有带时间戳的标注段，支持筛选和审核
3. **合理性标记**: 标记每个标注段是否合理（待审核/合理/需要修改）
4. **JSON编辑器**: 可视化编辑JSON标注内容

## 启动方式

### 1. 启动后端服务

```bash
# 在项目根目录下
python -m uvicorn backend.api:app --reload --port 8000
```

### 2. 启动前端应用

```bash
# 在项目根目录下
streamlit run frontend/app_annotation_checker.py
```

## 使用流程

### 1. 选择标注文件

在左侧边栏中选择要检查的标注文件（JSON格式），系统会自动加载：
- 视频ID和基本信息
- 角色数量
- 欲望分析数量
- 转换数量
- 行为序列数量

### 2. 视频播放对照

在"视频播放对照"标签页中：
- 查看视频播放器
- 使用右侧的快速跳转按钮查看对应时间段的标注
- 查看选中标注段的详细信息
- 标记标注段的合理性并添加审核备注

### 3. 标注段列表

在"标注段列表"标签页中：
- 查看所有标注段的统计信息
- 按类型、审核状态、角色进行筛选
- 批量审核标注段
- 查看每个标注段的详细数据

### 4. JSON编辑器

在"JSON编辑器"标签页中：
- 直接编辑JSON内容
- 保存修改后的标注数据
- 查看JSON结构信息

## 标注段类型

平台支持以下类型的标注段：

1. **角色初始状态** (`character_initial_state`): 角色的初始状态和时间戳
2. **角色最终状态** (`character_final_state`): 角色的最终状态和时间戳
3. **欲望动机分析** (`desire_motivation`): 欲望动机分析的时间范围
4. **欲望转换** (`desire_transition`): 欲望转换的时间范围
5. **行为序列** (`behavioral_sequence`): 行为序列的时间范围
6. **QA关键段** (`key_segment_qa`): 用于QA的关键时间段

## 审核状态

每个标注段可以标记为以下状态：

- **⚪ 待审核** (`pending`): 尚未审核
- **✅ 合理** (`approved`): 标注合理，无需修改
- **⚠️ 需要修改** (`needs_revision`): 标注存在问题，需要修改

## API端点

后端提供以下API端点：

- `GET /annotations_test/list`: 列出所有标注文件
- `GET /annotations_test/{video_id}`: 获取指定标注文件
- `GET /annotations_test/{video_id}/segments`: 获取标注段列表
- `POST /annotations_test/{video_id}/segments/{segment_id}/review`: 更新标注段审核状态
- `PUT /annotations_test/{video_id}`: 更新整个标注文件
- `GET /videos/file`: 通过路径获取视频文件

## 注意事项

1. **视频路径**: 确保JSON文件中的 `video_path` 字段指向正确的视频文件路径
2. **文件格式**: 标注文件必须是有效的JSON格式
3. **时间戳**: 所有时间戳以秒为单位
4. **保存操作**: 修改标注内容后记得点击保存按钮

## 故障排除

### 无法连接到后端API

- 检查后端服务是否已启动
- 确认端口号是否为8000
- 检查防火墙设置

### 视频无法加载

- 检查 `video_path` 字段是否正确
- 确认视频文件是否存在
- 检查文件路径是否为相对路径或绝对路径

### JSON格式错误

- 使用JSON验证工具检查格式
- 确保所有括号和引号匹配
- 检查是否有特殊字符需要转义
